## 测试用例列表

### TC-INT-001: 用户注册 - 正常流程
**优先级**: P0 | **类型**: API测试

**前置条件**:
- 数据库连接正常
- 邮箱未被注册

**测试步骤**:
1. 发送POST请求到 `/api/auth/register`
2. 请求体:
```json
{
  "email": "newuser@werss.com",
  "password": "Password@123",
  "nickname": "TestUser"
}
```

**预期结果**:
- [ ] HTTP状态码: 200
- [ ] 响应包含 `success: true`
- [ ] 响应包含用户ID和邮箱
- [ ] 数据库中创建新用户记录
- [ ] 密码已加密存储

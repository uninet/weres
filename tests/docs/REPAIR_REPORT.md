#### 1.2 修复操作

**修复1：统一数据库配置**
```bash

DATABASE_URL="postgresql://postgres:postgres@localhost:5432/werss3?schema=public"

# 修改后 (.env.local)
DATABASE_URL="file:./dev.db"
```

**修复2：执行数据库迁移**
```bash
npx prisma migrate dev --name init
npx prisma generate
```

**修复3：创建测试数据**


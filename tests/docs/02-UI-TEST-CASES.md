## 测试用例列表

### TC-UI-001: 页面布局验证 - 三栏式布局
**优先级**: P0 | **类型**: 布局测试

**前置条件**:
- 用户已登录
- 已订阅至少一个RSS源
- 已同步文章数据

**测试步骤**:
1. 访问阅读器页面 `/reader`
2. 观察页面整体布局

**预期结果**:
- [ ] 页面显示三栏式布局：左侧导航栏、中间文章列表、右侧阅读区
- [ ] 左侧导航栏宽度约 256px（展开状态）
- [ ] 中间文章列表宽度约 420px
- [ ] 右侧阅读区占据剩余空间
- [ ] 各栏之间有明显分隔线
- [ ] 无布局错位或元素重叠
